## Quick start

Install Docker with Compose v2. In Linux/WSL or Git Bash:

```bash
cp .env.example .env
# Edit .env and choose your own local POSTGRES_PASSWORD.
docker compose up -d --build
curl --fail http://localhost:8080/actuator/health
curl --fail http://localhost:8080/api/ziyayev-olzhas
bash scripts/test_api.sh
```

Application startup can take a minute. `test_api.sh` waits for readiness.
On PowerShell: `Copy-Item .env.example .env`, edit `.env`, then the same
`docker compose` commands. Run Bash scripts in WSL/Linux or Git Bash.

## API

Base URL: `http://localhost:8080/api/ziyayev-olzhas/students`.

| Method | Path suffix | Result |
| --- | --- | --- |
| POST | (none) | Create student, HTTP 201 and Location |
| GET | (none) | List students, HTTP 200 |
| GET | /{id} | Get student, HTTP 200 or 404 |
| PUT | /{id} | Update an existing student, HTTP 200, 400 or 404 |
| DELETE | /{id} | Delete student, HTTP 204 or 404 |

Example body (the email is sample test data):

```json
{"fullName":"Ziyayev Olzhas","groupName":"IT2-2302","email":"olzhas@example.com"}
```

## Build and tests

Personal feature by Ziyayev Olzhas: PUT validates incoming fields, updates the
existing record transactionally and returns 404 without inserting a new record
when the ID is absent. Regression tests cover successful persistence, a missing
record and rejection of invalid updates without changing stored data.

Requires a working JDK 21. Database-free tests use an isolated H2 database
in PostgreSQL compatibility mode. Real PostgreSQL is used in Compose;
H2 results alone do not demonstrate PostgreSQL integration or persistence.

```bash
./gradlew clean test bootJar
```

On Windows: `.\gradlew.bat clean test bootJar`.
HTML results: `build/reports/tests/test/index.html`.
Run outside Docker only when PostgreSQL is available, with `DB_URL`,
`DB_USERNAME` and `DB_PASSWORD` environment variables, then `./gradlew bootRun`.

credentials in environment variables and Jenkins secrets in Jenkins Credentials.
Committed secrets remain recoverable from Git history even after deleting a file.
